# apps/demo-store — Phase 1

A fake eyewear ecommerce store (catalog, product pages, prices, cart, fake
checkout) that embeds `@lumiframe/sdk` like any real merchant would. This is
how the full loop — SDK → widget → API → worker → mock provider → result →
add-to-cart → fake order → attribution — gets tested end-to-end
(`ARCHITECTURE.md` §16, product spec §50) without needing a real merchant
or a real AI vendor.

Not yet implemented — this is a placeholder for Phase 1.
