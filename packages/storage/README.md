# packages/storage — Phase 1

Thin wrapper over Supabase Storage (S3-compatible): private buckets for
customer photos, try-on results, and processed product assets; signed URL
generation; retention/expiry sweep honoring `CUSTOMER_IMAGE_RETENTION_HOURS`
and `TRYON_RESULT_RETENTION_HOURS` (`ARCHITECTURE.md` §11).
